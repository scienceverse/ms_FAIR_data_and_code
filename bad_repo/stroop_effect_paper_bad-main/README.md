# Stroop effect study (bad-practice example)

This repository is a deliberately flawed companion to
[Lakens/stroop_effect_paper](https://github.com/Lakens/stroop_effect_paper),
built to demonstrate what [Metacheck](https://github.com/scienceverse/metacheck)
catches when common data-sharing, reporting, and reproducibility mistakes are
present. **The data and the underlying `t.test()`/plotting code are real**;
the sentences reporting the results have been deliberately edited to no
longer match what that code actually produces, some reported results are
not computed by the code at all, and the code stops with an error before it
reaches the last analysis. Do not cite or reuse the numbers reported in
`analysis.pdf` as if they were genuine findings.

See [Lakens, Mesquida & DeBruine, "Best Practices for Machine Readable Data
and Code Sharing in Psychology"](https://github.com/scienceverse/ms_FAIR_data_and_code)
for what this repository deliberately does *not* do.
